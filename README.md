# Noise Pollution Measurement System

A web-based project for monitoring and measuring environmental noise pollution levels.

## 📌 Features

- Measure surrounding noise levels
- User-friendly interface
- Responsive design
- Real-time data display
- Pollution awareness system

## 🛠️ Technologies Used

- HTML

- JavaScript
- TypeScript
- Vite
